# Active Task Handoff

This file records current contributor work and completed handoffs awaiting review. Follow the [active-task workflow](workflow.md#active-task-handoff) before implementation, when handing off, and after completing an assignment. Approved feature task status remains in its `tasks.md`; this file is a resumable working summary.

Use `node scripts/ci/active-task.mjs --help` to manage your own owner/task entry. Keep the goal, next action, verification, and blockers current. A completed worker leaves its result for the coordinator; clear it after review and durable evidence recording. Blocked or interrupted entries remain available for continuation.

The script preserves these instructions and changes only the managed data below. An empty array is the commit-ready baseline; the file and its markers remain in the repository. Keep secrets and raw logs out of entries; link to approved evidence instead.
